# HyperSlop

A landing page experiment for a made-up "AI agent" coin.

It is fictional: there is no token, no contract address, no wallet connect and no buy button.

Open `index.html` in a browser. No build step. To host it, enable GitHub Pages on the `main` branch.

What's in it: a scrolling ticker, a typed "agent" terminal, a narrative generator with a slop meter, fake tokenomics, a roadmap where everything is Q3, and an honest FAQ.

## The lab

Seven small experiments, each on its own page:

- `quiz.html` Slop or Not? (a guessing game)
- `card.html` coin card maker (downloads a PNG stamped "parody")
- `translate.html` trenches translator
- `whitepaper.html` whitepaper generator (printable)
- `founder.html` founder post generator
- `bingo.html` red-flag bingo
- `chart.html` number go up (drag the last candle)

Shared styles and helpers live in `lab.css` and `lab.js`.
